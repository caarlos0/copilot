# home

An agent for household electricity, solar power, and battery backup. It has a
Brazil-first focus.

## Install

```sh
copilot plugin marketplace add caarlos0/copilot
copilot plugin install home@caarlos0
```

## Agents

Start it with `copilot --agent home:electric-engineer`.

| Agent | Use it to |
| --- | --- |
| `electric-engineer` | Estimate consumption, size solar and batteries, compare backup options, read electricity bills, and understand Brazilian voltage, frequency, and supply types |

## Skills

This plugin has no skills.
