# terminals

Skills for the design of command-line tools and terminal user interfaces.

## Install

```sh
copilot plugin marketplace add caarlos0/copilot
copilot plugin install terminals@caarlos0
```

## Skills

| Skill | Use it to |
| --- | --- |
| `cli-design` | Design or review commands, flags, help, output, prompts, configuration, and exit behavior |
| `tui-design` | Design or review a full-screen terminal app or an interactive command-line tool |

Ask Copilot to use a skill by name. The `coding` plugin uses these skills for
its command-line and TUI work.

## Agents

This plugin has no agents.
